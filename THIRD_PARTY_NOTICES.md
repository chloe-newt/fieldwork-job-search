## AI Job Search

The employer catalogue (names, ATS providers and board identifiers) in `src/catalog.mjs` is adapted from the supplied `job-search-master.zip`, whose README identifies [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search) as its upstream project. Its public ATS approach also informed the Ashby connector. Fieldwork uses its own native JavaScript implementation and does not install or execute the upstream AI skills, Bun tools, Indeed scraper or agent configuration.
